> **A perfectly normal BMI calculator that takes your result far too seriously.**

## Project Description

BMI: The Judgment Engine is a deliberately over-engineered BMI calculator that turns a simple health calculation into a completely unnecessary judgment experience.

Enter your details, calculate your BMI, and prepare yourself for dramatic reveals, roasts, meme reactions, sounds, animations, and special Easter eggs.

Because apparently, calculating one number wasn't enough.

---

## The Problem (that doesn't exist)

People can calculate their BMI in a few seconds.

But what if that experience was **far too boring?**

Where is the suspense?

Where is the judgment?

Where are the completely unnecessary sound effects?

Where is the website dramatically reacting because you entered **67 kg**?

These are the real problems.

---

## The Solution (that nobody asked for)

Introducing **BMI: The Judgment Engine**.

It takes a completely ordinary BMI calculation and turns it into an unnecessarily dramatic event.

The website:

* Calculates your BMI
* Determines your BMI category
* Dramatically reveals your result
* Gives you a personalized roast
* Plays meme sound effects
* Reacts differently to special numbers
* Includes hidden Easter eggs
* Randomly generates different meme reactions
* Provides an optional AI-powered roast
* Allows users to share their result
* Supports accounts and BMI history

The calculation is serious.

The website's reaction is not.

# Implementation

## BMI Calculation

The project uses the standard BMI formula:

**BMI = Weight (kg) / Height² (m²)**

The application supports both metric and imperial input.

Users can enter:

* Age
* Sex
* Height
* Weight

The result is then processed by the Judgment Engine.

---

## The Judgment Engine

The result isn't simply displayed as a number.

The application progressively reveals:

1. **Calculation**
2. **Suspense**
3. **BMI value**
4. **BMI category**
5. **Verdict**
6. **Roast**
7. **Meme reaction**
8. **Sound / animation**

The goal is to make a completely ordinary calculation feel unnecessarily important.

---

## Special Number Easter Eggs

Certain weight values trigger dedicated reactions.

Examples include:

* **42 kg** — The answer to everything
* **50 kg** — Halfway to something
* **67 kg** — SIX SEVEN
* **73 kg** — The objectively superior number
* **77 kg** — Double seven
* **88 kg** — Double eight
* **99 kg** — So close...
* **100 kg** — The century

These reactions can include unique text, animations and sound effects.

The system also contains random meme reactions for ordinary results so that the experience doesn't become predictable.

---

## Audio System

The project uses locally stored audio assets for its meme reactions.

Audio is triggered only after user interaction to remain compatible with modern browser autoplay restrictions.

A mute control is provided so users can silence the Judgment Engine when necessary.

---

## AI Integration

AI is used as an **optional enhancement**, rather than as the core of the application.

The AI can generate an additional personalized roast based on the user's result.

The AI does **not** perform the BMI calculation or provide medical advice.

If the AI service is unavailable, the application falls back to locally stored roast content so the main experience continues to work.
